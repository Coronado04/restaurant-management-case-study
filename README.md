# La Cantina de Sabina — Restaurant Web Platform

**Full-Stack Development | Real-World Project | Saav Studio**

> This is a public portfolio case study. The production source code, private configurations, credentials, and customer information are not included.

## Overview

La Cantina de Sabina is a restaurant in Heredia, Costa Rica. Our team developed a responsive public website and administrative functionality for managing reservations, menu content, and events.

## Problem and Solution

The restaurant initially received reservations through social media and telephone calls. The platform provides an online reservation interface and administrative workflows to support restaurant operations.

## Features

- Responsive customer-facing restaurant website.
- Online reservation submissions and administrative reservation management.
- Public menu and administrative menu management.
- Events information and management.
- JWT-based administrator login and protected interfaces.
